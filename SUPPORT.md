# Support

This repository is a community-supported tool for generating CodeQL language
extractors. Support and maintenance are provided on a best-effort basis; a
response or fix is not guaranteed.

## Getting help

- For bugs and feature requests, [search existing issues](https://github.com/advanced-security/codeql-extractor-generator/issues)
  first, then [open an issue](https://github.com/advanced-security/codeql-extractor-generator/issues/new)
  with a clear description and relevant environment details.
- For questions about using CodeQL, see the
  [CodeQL documentation](https://docs.github.com/en/code-security/codeql-cli).
- Do not use public issues to report security vulnerabilities. See
  [SECURITY.md](SECURITY.md) for private reporting instructions.

Support for this project is limited to these public resources.
